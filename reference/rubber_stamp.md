# The right table rubber stamps

Merge, but only keep rows that are rubber stamped by the right table
(right join equivalent)

## Usage

``` r
rubber_stamp(x, y, ...)
```

## Arguments

- x:

  A data frame or tibble (main table)

- y:

  A data frame or tibble (rubber-stamping table)

- by:

  Columns to join by

## Value

A merged data frame
